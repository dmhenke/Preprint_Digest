4. Prioritizing peptides for targeted mass spectrometry experiments using deep learning

Field Detail
Source BIORXIV
DOI 10.64898/2026.05.21.727053
Full Text Read Preprint
Impact Score ░░░░░░░░░░ 0.000

Core Problem: Selecting reliable, high-performing peptides for targeted mass spectrometry quantification is challenging because existing methods are limited by prior empirical data or fail to accurately predict peptide response from sequence alone.

Proposed Solution: The authors developed Bromo, a transformer-based deep learning model that predicts the relative response of peptide precursors from a given protein while explicitly incorporating the precursor charge state. This model is trained on millions of annotated peptide pairs derived from large-scale data-independent acquisition mass spectrometry data.

Key Impact: Bromo provides a highly adaptable and robust tool for optimizing target peptide selection, significantly improving the development of selected and parallel reaction monitoring assays across diverse experimental conditions.

Methodology Highlight: Bromo's architecture allows for fine-tuning on experiment-specific data, enabling it to account for variable influences such as sample matrix, sample preparation, and instrument platform.
