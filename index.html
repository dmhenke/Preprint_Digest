2. Tumour architecture shapes polarized epithelial states that predict survival in high-grade serous ovarian cancer

BIORXIV · DOI: 10.64898/2026.05.27.727977 · Score: ███████░░░ 0.745

Core Problem: Epithelial heterogeneity defines high-grade serous ovarian carcinoma (HGSC), yet principles that generate this diversity within and across tumours remain unclear

Proposed Solution: Integrating single-cell RNA sequencing (scRNA-seq) data from 13 studies (1,980,703 cells, 371 samples), we resolve a dominant axis of secretory cell polarization spanning proliferative, progenitor-like SecA cells and quiescent SecB cells expressing a mucosal injury response program. Targeted spatial transcriptomics across 8 whole HGSC tissues and a 97-patient tissue microarray shows this axis is spatially deterministic: tumour architecture shapes a hypoxic gradient along which SecB cells localize to avascular, luminal regions, where HIF/NF-{kappa}B-driven survival and glycolysis displace the mitogenic signalling of SecA

Key Impact: Tumour architecture is thus a primary axis of malignant identity in HGSC, coupling microenvironment, cell state, and immune niche to clinical outcomes

Methodology: Single-Cell techniques were central to the study design.

5. Assessing and Optimizing Low-Frequency Somatic Mutation Detection: A Multi-Platform High-Throughput Sequencing Perspective

BIORXIV · DOI: 10.64898/2026.05.28.728367 · Score: ██████░░░░ 0.628

Core Problem: Systematic performance comparison of multiple short-read sequencing platforms is necessary, especially for challenging applications like detecting low-frequency somatic mutations.

Proposed Solution: The authors generated a large-scale, multi-platform dataset using PosMix to simulate position-specific variant allele frequencies, and subsequently developed SomaticXGB, a machine learning caller to improve detection accuracy.

Key Impact: This work provides a standardized, rich multi-platform data resource and a robust machine learning pipeline for optimizing the detection of low-frequency somatic mutations across diverse sequencing technologies.
